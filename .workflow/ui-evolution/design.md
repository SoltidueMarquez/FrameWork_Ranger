# UI 资源配置与组件扩展设计（审阅稿）

日期：2026-09-10。整体设计已经用户“没什么问题，执行吧”批准；本稿作为实施依据保留，当前实现和验收进度见 progress.json。

## 1. 资源配置与实际操作

采用 `GlobalUIModule → UIResourcesConfig → UIPanelConfig` 三层结构。中央 GlobalConfig 仍只安装一个 UI 模块；该模块指定一份总配置。工程可以保存多份总配置，但只有被已安装模块引用的一份参与运行。

总配置拥有 Global/Scene 两组域及面板目录。域决定渲染方式、排序与缩放；面板目录引用独立面板 SO。单面板 SO 集中配置 key、所属域、层级、Prefab 来源、Logic 模板、互斥/模态、关闭策略及开关动画。是否收录、适用场景、自动打开、必须成功属于总配置中的条目设置。同一面板 SO 可以被不同总配置复用，运行实例不写回模板。

项目中心主下拉改为选择资源总配置，显示名称、路径和项目使用标记，保持选择记忆与资产变化刷新。下拉只改变编辑对象；“设为项目使用”才在校验后写入唯一 UI 模块的资源引用。已有 UI 模块时保留模块资产及其在 GlobalConfig 中的位置；没有时通过明确的安装入口创建/指定模块并校验 ResourceModule 依赖；重复 UI 条目、缺失中央配置均给具体原因，不猜测目标。创建总配置不自动安装。

单面板 SO 的 Prefab 字段是实际资源入口，支持拖拽与选择。新建默认为直接引用，任意正常项目 Prefab 目录均可；也可明确选择 Resources/Addressables，通过资源模块按需加载。地址模式的编辑器 Prefab 选择只帮助解析与校验，不把硬引用带入运行资源目录。不会静默切换后端或把缺失引用回退为另一路径。直接引用会由配置持有 Prefab 依赖，销毁窗口不代表该 Prefab 资源已卸载。

中文编辑器复用同一套域、面板和目录绘制，覆盖资产 Inspector、模块内嵌与项目中心；保留 Odin 多态 Logic、按模式显隐、合理标签宽度与窄窗口纵向布局。独立打开面板 SO 时明确显示域下拉所依据的总配置/目录；存在多个引用上下文时可切换校验上下文，不隐式修改使用它的其他总配置。运行期间禁止修改模板与切换生效配置。新建业务总配置只含默认域与空面板目录；新增面板可从已有 Prefab 创建 SO，或创建带 UIView 的骨架。View 引用继续手动绑定，不做业务/绑定代码生成。

## 2. 场景与运行流程

保留一个 GlobalUIModule、三种渲染域、Logic/View 分离、owner/key 单实例、明确父子关系、互斥与模态规则、保留/销毁策略以及场景轮次隔离。对已打开面板重复手动 Open 仍刷新并同层置顶，不重放 OnOpen 或入场动画。

Scene 目录按面板选择适用场景，支持全部场景或明确列表；未列入适用范围的面板手动打开也失败。编辑器使用场景资产身份维护引用，并随移动更新运行时路径。自动打开独立配置，默认关闭，适用于该条目允许的场景；“必须成功”默认关闭，仅在自动打开启用时显示。新配置不要求每个场景再建 UI 模块或独立 UI 总配置。

在现有 Starting/Ending 生命周期外增加可选的 Scene 就绪通知：场景模块和 Driver 的加载后处理完成之后、SceneScope 宣布就绪之前通知参与者。使用独立可选接口，不迫使原 ISceneScopeLifecycle 实现者增加方法。Core 只负责生命周期顺序、取消与回滚，UI 负责过滤及打开目录。开始通知仍在场景模块前创建上下文，结束通知仍在场景模块卸载前清理；空 Scope 同样通知，预检失败保留旧 Scope/UI。

自动打开按目录顺序执行，不额外传业务数据；Logic 读取自身模板或已加载业务模块。需要临时数据/父面板的窗口由业务显式打开。业务已提前打开的面板直接跳过，不刷新、不置顶。普通自动打开失败清理该尝试并报告后继续；必须成功失败通过现有加载异常路径回滚本轮 SceneScope，保留 Global，不自动回到旧 Unity 场景。取消及结束轮次不继续打开后续面板。首次缺少 Camera/World 绑定依旧明确失败，不无限等待绑定。

实施默认值：本轮自动打开针对 Scene 条目，Global 继续通过业务显式打开；不额外引入 Global 启动自动打开或预加载状态。适用场景及自动打开是总配置条目的规则，不由单面板 SO 或 Prefab 自己判断。

## 3. 动画、输入与组件

面板动画按面板配置，可组合淡入淡出、缩放和滑动及其时长，默认无动画，使用不受 Time.timeScale 影响的 UI 时间。动画使用 UI 自有呈现节点，布局、窗口拖动与动画偏移不争用同一变换。入场从开始即应用模态限制，完成后允许自身操作；退场立即禁用自身，完成后才撤销模态限制与恢复有效焦点。父面板关闭联动自身依附子树，强制卸载跳过退场并立即完成清理。

保留 OpenAsync、OpenChildAsync、Refresh、Close 等入口，增加可等待退场结束的 CloseAsync。实施默认值：OpenAsync 完成时入场已结束；Close 发起退场，CloseAsync 可等待退场与关闭策略执行。OnOpen/OnClose 分别在本轮入场/退场开始调用一次；OnClose 可解除订阅，View 在正常退场期间仍由 UI 持有。关闭中重开排队至本次关闭完成，然后按策略开始新一轮，不撤销已发生的 OnClose。重复关闭共享完成结果；关闭父面板时对子项发起联动退场并等子项清理后完成父项清理。Global 已打开域失绑仍暂停呈现与输入；进行中的呈现动画收敛到目标状态，重绑定不重放 OnOpen/动画，避免等待永久悬挂。

| 子系统 | 本轮范围 |
| --- | --- |
| UIImage / UIRawImage | 原生图片兼容、换图、尺寸/比例适配、透明度、射线开关，中文扩展参数与创建菜单 |
| UIButton | 左右键点击与按下/松开、悬停、导航焦点和中断事件；保留长按，加入按需开启的双击、连续触发、拖拽回调 |
| 状态表现 / UIToggle | 多目标颜色、图片、显隐、Animator；焦点与开关值分离；静默改值仍刷新外观，接入选择组 |
| 图形效果 | 独立基础线性渐变；同 Canvas 图片组的透明轮廓合成描边，提供颜色/粗细，重叠处不重复描边 |
| 窗口拖动 | 标题/拖动区、目标与可选移动范围，三种域通用，输入中断或关闭时结束拖动 |
| 折叠组 | 标题、内容、初始状态、独立/手风琴模式、箭头状态同步、即时切换与布局刷新，保留内容实例 |
| 基础布局 | 子项对齐、偏移、是否控制尺寸，内容宽高上下限；增强现有横纵/网格/忽略/适配与统一调度 |
| 工具与普通列表 | RectTransform/坐标、显隐交互、图片文字、可解除订阅、滚动定位和平滑滚动、按 key 复用及刷新时位置保持 |

实施默认值：双击扩展不延迟原单击，第二次有效点击额外发送双击事件；触发长按/连续触发/实际拖拽后不补发普通点击。拖拽事件通过按需启用的独立组件接入，普通按钮不抢走 ScrollRect 的拖动。所有订阅工具只解除自己添加的监听。平滑滚动由用户拖动、新定位或关闭中断；列表保留可见 key 与偏移，key 被删除时回退到邻近项并约束有效滚动范围。

简单整体描边首期对象为 Image/UIImage，支持普通精灵及其透明形状，效果结果服从所属 Canvas 的裁切与排序，不参与射线、不绕过模态。合成资源归组件所有，只在内容/几何/尺寸变化时刷新，销毁时释放；原图不强制开启 CPU Read/Write。具体采用兼容项目 URP 的合成渲染，不把 HTY 的专用全局交互或补间依赖带入 Ranger。实施前先用重叠透明图片、遮罩和三种 Canvas 的小样例验证渲染路线。

仍暂缓多实例、虚拟列表、流式/环形布局、绑定代码生成；整体描边暂不扩展到 RawImage、文字或复杂自定义材质；额外 UV、自定义网格、复杂材质/文字动画不在本轮范围。窗口动画不等同于通用补间框架，优先使用现有 Unity/UniTask 能力。

## 4. 兼容、样例与实施顺序

保留 GlobalUIModule、现有 Prefab、场景和脚本 GUID，不删除当前项目条目或无关修改。旧内嵌 GlobalConfiguration/SceneConfiguration 字段保留为兼容读取/迁移数据；已指定新总配置时以新配置为准，不把两份目录混合。旧字段的数据入口与新 SO 的关系在说明中明确，不承诺运行时修改模板改变已建立的上下文。

提供明确的旧目录提取工具，先生成独立总配置和每个面板 SO，校验/保存重载成功后再关联模块；失败不切换生效引用。保持 key、域参数、Logic 多态与引用、资源后端/地址、关闭关系等值。迁移原地址加载不强制改成直接引用。旧 Scene 条目转换为全部场景可用、自动打开关闭，以保持既有业务调用行为。保留旧数据用于回退，重复执行不复制已有提取结果；模块引用切换支持 Undo。已生成的新资产不由一次撤销盲删。

当前静态搜索仅发现 Samples/Generated/GlobalUIModule.asset 一份模块配置。将其提取为明确命名的演示总配置与面板 SO，保留现有模块资产和项目引用；样例目录/界面明显标注演示用途。另提供新增 Scene 适用范围、自动打开成功/失败、组件和动画的可操作示例，避免把演示条目塞进新建业务配置。

实施分为可验收片段：资源 SO 与兼容提取 → Scene 过滤/就绪通知/自动打开 → 动画与关闭输入状态 → 图片/按钮/状态/拖动/折叠 → 布局/列表/工具 → 编辑器整合与文档验收。新图形合成路线在扩大组件实现前先做针对性验证。延续 ResourceModule 依赖；直接 Prefab 使用 UI 内部适配，不新增通用资源后端、不修改现有 ResourceBackendKind 数值。
