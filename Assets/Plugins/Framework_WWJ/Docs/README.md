- **事实**：已经在旧代码、Unity 资产或 Git 历史中验证过的内容。

- **暂定方向**：开始新设计时值得讨论的候选方案，必须结合后续参考项目重新确认。

- 新架构开始实现后，优先更新本目录，而不是把关键设计只留在聊天或代码注释中。
- 历史文档不代表新实现必须兼容旧 API。
- 第三方依赖（例如 Sirenix Odin、DOTween）不属于 Framework_WWJ 核心源码；是否继续使用，要在新设计阶段单独决策。
