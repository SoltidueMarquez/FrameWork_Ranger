# ADR-EC-004：预览页签与固定页面快捷入口

- 状态：已接受
- 日期：2026-08-18
- 所属阶段：Phase 1.3——预览页签与固定快捷页签

## 背景与约束

Phase 1.2 同时保留了左侧最近访问和持久化的多标签列表。两者都在表达“访问过的页面”，信息重复；普通浏览也会不断增加长期页签，无法区分临时查看和用户主动保留的快捷入口。

## 候选方案

1. 只删除最近访问，继续持久化所有打开页签。
2. 使用单个临时预览页签，并允许用户把页面固定为长期页签。
3. 用收藏列表完全替代页签。

## 决定

采用方案 2。Framework Center 同时维护有序固定页列表和一个不持久化的预览槽位。打开普通页面替换预览；打开固定页面只激活已有固定页。图钉负责在两种所有权之间转换，固定页支持拖拽排序。

固定页顺序与最后活动固定页写入 `Library/Framework_WWJ/FrameworkCenterState.json`。旧状态没有显式固定意图，因此不把 `openTabs` 或最近访问迁移为固定页；缺少 v2 版本号时建立干净状态。没有可恢复固定页时，概览作为预览回退页。

## 影响与明确非目标

- 左侧导航只承担页面目录和搜索，不再承担历史记录。
- 顶部栏明确区分用户固定的快捷入口和当前临时浏览页。
- 页面扩展 API、页面实例、帮助路由和页面生命周期签名不变。
- 不保存预览页、页面内部滚动位置或表单状态。
- 不实现跨窗口拖出、拆分视图或固定页分组。

## 验证方式

- EditMode 验证状态版本、清理、预览替换、固定转换、关闭回退和固定顺序移动。
- 人工验证页签视觉、图钉、拖拽、横向溢出、帮助页与快捷键。
