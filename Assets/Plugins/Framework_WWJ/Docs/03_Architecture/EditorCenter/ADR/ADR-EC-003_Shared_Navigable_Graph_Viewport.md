# ADR-EC-003：共享可导航图视口

- 状态：已接受
- 日期：2026-08-07
- 所属阶段：Phase 1.2——Editor Center 视觉与节点图交互优化

## 背景与约束

Phase 1.1 的代码架构图和模块依赖图各自使用固定 Canvas 与 ScrollView，只能操作滚动条。两套绘制器若分别实现缩放和平移，会产生不同的输入语义、坐标换算和点击误差。

## 候选方案

1. 两个 Drawer 各自增加滚轮和拖动代码。
2. 建立共享 IMGUI 图视口，具体 Drawer 只负责确定性布局和内容绘制。
3. 迁移到 GraphView 或 UI Toolkit。

## 决定

采用方案 2。Editor 内部共享视口统一保存 Zoom、Pan 和适配请求，负责鼠标中心缩放、中键/Alt+左键平移、裁剪、网格、工具栏和 Canvas/Viewport 坐标换算。缩放范围固定为 35%–200%。

节点仍按各自算法自动布局。初次打开、架构筛选变化和场景组合变化请求适配全部节点；搜索高亮不会改变布局或视角。节点绘制器使用视口提供的变换结果处理连线、标签、点击和双击。

## 影响与明确非目标

- 架构图与模块图获得一致的鼠标语义和缩放范围。
- 纯视口数学可以由 EditMode 测试，不依赖真实窗口事件。
- 不允许节点拖动，不保存坐标，不实现缩略图、框选、多选或自动编辑配置。
- 不引入 GraphView、UI Toolkit 或新的第三方依赖。

## 验证方式

- EditMode 验证鼠标锚点不漂移、缩放钳制、平移、100% 重置与适配计算。
- 人工在两类图中分别验证 35%、100%、200%、平移、适配、节点选择和源码双击。
