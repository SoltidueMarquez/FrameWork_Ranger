# ADR-POOL-002：严格所有权与循环缩容

- 状态：已接受
- 日期：2026-08-31
- 所属阶段：Pooling

## 背景与约束

字符串静默失败、值相等和只记录空闲列表都无法可靠区分外来、重复、错池与已借出对象。单纯 `MaxRetained` 也不能在峰值后按稳定节奏恢复容量。

## 决定

共享 `TrackedPool<T>` 使用引用相等的空闲集合、借出集合与空闲栈。Throw API 明确拒绝非法归还，Try API 仅把预期所有权错误映射为 `false`。循环缩容只在完全无借出后计时，忙碌会重置完整周期；每次到期移除一个扩容批次且不低于 InitialCount。

## 影响与非目标

池为严格单线程运行结构，不加锁。`MaxRetained` 只约束空闲对象，借出数量没有硬上限。首版不提供强制归还全部对象的业务 API。

## 验证

EditMode 覆盖外来/重复归还、有限保留、批量扩容、计时重置、回调失败、Clear 与 Shutdown；PlayMode 覆盖错池和外部销毁。
