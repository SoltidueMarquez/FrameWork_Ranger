## 3. 新增与更新的 EditMode 覆盖

- 默认折叠根卡片尺寸、紧凑排列和无重叠。
- 搜索临时展开不污染用户展开集合或位置 revision。

- 嵌套节点左上边界约束、展开根分组子树整体移动和缩放拖动换算。

以下项目依赖真实 Editor 视觉与鼠标感受，不以 batchmode 自动化代替。请在 `Framework_WWJ/Framework Center > 代码架构` 中确认：

- [ ] 20% / 50% / 100%：次要文字按层级隐藏，标题和结构不过度拥挤。
