# Phase 1.6：紧凑可展开架构节点图实施计划

> 状态：已实施，自动化验收通过；真实窗口视觉检查待确认  
> 日期：2026-08-22  
> 决策：[ADR-EC-007](./ADR/ADR-EC-007_Compact_Expandable_Architecture_Graph.md)

## 1. 目标

Phase 1.6 保留现有 IMGUI、生产程序集目录、搜索、详情面板和共享图视口，把 Phase 1.5 的“纵向嵌套泳道 + 全局七列”改造成紧凑复合图：折叠时每个根分组是一张可连接的大卡片，展开后在原地成为只包围直接子组和直属类型的容器。

视觉和交互取 HTY 状态机的展开、聚焦思路，以及 YokiFrame 的圆角卡片、曲线箭头和主题层级作为参考；不引入钻入导航、Avalonia、UI Toolkit 或 GraphView。

## 2. 已实施范围

### 2.1 复合布局

- 根分组和同级折叠分组按目录稳定顺序横向排列，并以固定行容量确定性换行。
- 折叠分组固定为 `258 × 96` 紧凑卡片；展开分组只包围自己的直接子组和直属类型。
- 类型列由当前分组实际出现的 `FrameworkArchitectureLayer` 决定，不再预留全局七列。
- 正向人工偏移会扩展父容器的右、下边界；嵌套分组和类型不能越过父内容区左上边界。
- 隐藏类型继续映射到最近的折叠祖先；显示关系按源端点、目标端点和关系种类聚合。

### 2.2 绘制与阅读

- 大节点显示分组名、职责摘要、后代类型数、程序集数和展开状态。
- 小节点显示中文名、CLR 类型名、类型种类和局部逻辑层。
- 深浅主题分别使用圆角容器、卡片、Hover/Selected 边框、端口、贝塞尔曲线、箭头和聚合数量胶囊。
- 选中类型或分组后保留一跳关系与相关端点，降低无关节点和关系的透明度。
- 低缩放依次隐藏职责、类型元数据、局部分层和标题，20% 以下只保留卡片形状。
- 类型右键提供聚焦、Ping、打开源码和重置当前位置；分组右键提供展开/收起、聚焦和重置当前位置。

### 2.3 会话拖动与页面状态

- 折叠分组、展开容器标题和类型卡片共用拖动入口；拖动展开标题会移动其完整子树。
- 屏幕拖动量按当前缩放换算到画布坐标。
- 位置以 `G:<GroupId>` 和 `T:<AssemblyQualifiedName>` 保存非零偏移，只写入 `SessionState`。
- 鼠标释放、鼠标离开窗口或页面停用时提交；目录刷新时清理失效键。
- 搜索临时展开期间禁止拖动和改变展开状态。
- 工具栏增加“重置布局”、详情开关和快捷键提示；`F` 聚焦当前选择。

### 2.4 开销控制

- 架构目录仍只在页面激活或显式刷新时构建。
- `FrameworkArchitectureGraphLayoutCache` 以目录引用、展开 revision、位置 revision、搜索文本和关系筛选作为缓存键。
- 普通 Layout/Repaint 复用同一布局结果；拖动、展开、搜索或筛选变化才重建。
- 布局结果缓存分组绘制顺序、容器内容区、类型卡片、局部分层和关系曲线边界。
- 绘制器按视口裁剪；圆角顶点数组和 `GUIStyle` 复用，不为每个节点创建纹理。

## 3. 接口与边界

- Runtime 公共 API、模块生命周期、架构 Attribute、程序集接入方式和序列化资产格式均未改变。
- 新增代码仅位于 Editor 程序集；位置状态不会进入项目资产或版本控制。
- 折叠不删除位置偏移；只有节点菜单重置或工具栏“重置布局”会清除偏移。
- 不支持项目级坐标资产、多人共享布局、运行时编辑、缩略图或自由创建/删除关系。
- HTY/LyingBottle 和 YokiFrame 全程只读，本阶段不更新参考项目或其 Skills。
